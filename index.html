SUMMARY

Container-Level (Parent) Properties

These properties are applied to the element with display: flex: justify-content: Aligns flex items along the main axis (horizontal by default). Values: flex-start, flex-end, center, space-between, space-around, space-evenly. align-items: Aligns flex items along the cross axis (vertical by default). Values: flex-start, flex-end, center, baseline, stretch. flex-direction: Sets the direction of the main axis and order of elements. Values: row (default), row-reverse, column, column-reverse. flex-wrap: Controls whether items must stay on one line or can wrap onto multiple lines. Values: nowrap (default), wrap, wrap-reverse. flex-flow: Shorthand combining flex-direction and flex-wrap into a single declaration (e.g., flex-flow: row wrap). align-content: Controls alignment and spacing of multiple lines along the cross axis (only works when flex-wrap: wrap causes wrapping). Values: flex-start, flex-end, center, space-between, space-around, stretch.

Item-Level (Child) Properties

These properties are applied to individual items inside the flex container: order: Changes the display order of a specific item without modifying the HTML structure. Values: Any integer (default is 0, negative numbers move items forward, positive move them back). align-self: Overrides the parent container's align-items rule for that single flex child. Values: auto, flex-start, flex-end, center, baseline, stretch
